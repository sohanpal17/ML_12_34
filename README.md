
# MLOps Experiment - Laptop Price Prediction

## Aim
To build an automated machine learning pipeline using
MLOps concepts and Decision Tree Regression.

## Dataset
Laptop Price Dataset

## Algorithm
Decision Tree Regressor

## Workflow
1. Dataset Loading
2. Data Exploration
3. Data Preprocessing
4. Train-Test Splitting
5. Model Training
6. Model Evaluation
7. Model Saving
8. Prediction using Saved Model

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R2 Score

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib
- Git
